# Contributing

The full guide is [CONTRIBUTING.md](https://github.com/scobjuan/ticketboost/blob/main/CONTRIBUTING.md)
in the repository. In short:

1. Open an issue first for new features.
2. Set up the [local environment](local-environment.md).
3. Branch from `main`, commit with Conventional Commits, add tests.
4. `make check` and `make e2e` must pass.
5. Open a pull request with a Conventional Commit title.
