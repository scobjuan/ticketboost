# FAQ

## The panel opens when I press Ctrl by itself. Can I change that?

Yes. Change the leader key, require two or three taps, or switch to hold mode in your
[personal settings](../user-guide/personal-settings.md).

## Does TicketBoost bypass GLPI rights or rules?

No. Actions run on the server through the same GLPI classes the interface uses, so rights,
business rules, SLAs and notifications apply.

## Does it need the GLPI API?

No. It works with the normal user session.

## Which languages are available?

English and Spanish. TicketBoost follows the language selected in GLPI, including the
regional variants (for example Spanish (Mexico) or English (United States)).
