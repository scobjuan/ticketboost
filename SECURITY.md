# Security policy

## Supported versions

Only the latest minor release receives security fixes.

## Reporting a vulnerability

Do not open a public issue. Report it privately through
[GitHub security advisories](https://github.com/scobjuan/ticketboost/security/advisories/new)
or by email to scobjuan@gmail.com with the steps to reproduce, the affected versions
(TicketBoost, GLPI, PHP) and the impact.

You will receive an answer within 7 days. Once a fix is released, the advisory is
published with credit to the reporter unless anonymity is requested.

Vulnerabilities in GLPI itself must be reported to the GLPI project.
